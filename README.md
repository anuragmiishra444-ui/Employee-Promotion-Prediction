# Employee Promotion Prediction

A Machine Learning project that predicts whether an employee is likely to be promoted based on employee-related information.

## Features

- Employee Promotion Prediction
- XGBoost Machine Learning Model
- Confidence/Probability Score
- Interactive Streamlit Dashboard
- Model Performance Visualization
- Batch CSV Prediction
- Prediction History
- Downloadable Prediction Report

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- Matplotlib
- Seaborn
- Streamlit
- Pickle
